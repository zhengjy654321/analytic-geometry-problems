# 切线方程的三种证明与同构法推切点弦

> **专题**：切线统一体系 2/3 ｜ **适用模块**：七、第三定义、垂径定理、中点弦与光学性质

*(证明分两步走：第一步打地基——证明「点在曲线上 $\Rightarrow$ 切线方程」；第二步盖楼——利用「同构转化法」一步推出切点弦方程与切线交点轨迹。以下均以椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\ (a > b > 0)$ 为例，双曲线、抛物线、圆完全同理。)*

## 一、第一步：证明切线方程（三种方法全齐）

### 方法一：联立方程 + 判别式 $\Delta = 0$（高考解答题最规范通法）
设点 $P(x_0, y_0)$ 在椭圆上，则 $b^2 x_0^2 + a^2 y_0^2 = a^2 b^2$ ①。

- **当 $y_0 = 0$ 时**：$x_0 = \pm a$，切线为竖直线 $x = \pm a$，代入 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$ 显然成立。
- **当 $y_0 \neq 0$ 时**：切线斜率存在，设为 $k$，切线方程为 $y = kx + m$（其中 $m = y_0 - k x_0$）。联立椭圆方程：

$$\begin{cases} y = kx + m \\ b^2 x^2 + a^2 y^2 = a^2 b^2 \end{cases} \Rightarrow (b^2 + a^2 k^2)x^2 + 2a^2 km x + a^2(m^2 - b^2) = 0$$

由相切条件 $\Delta = 0$ 得 $4a^4 k^2 m^2 - 4a^2(b^2 + a^2 k^2)(m^2 - b^2) = 0$，化简得 $m^2 = a^2 k^2 + b^2$。将 $m = y_0 - kx_0$ 代入并结合 ① 式 $a^2 b^2 - b^2 x_0^2 = a^2 y_0^2$：

$$(y_0 - kx_0)^2 = a^2 k^2 + b^2 \Rightarrow (a^2 - x_0^2)k^2 + 2x_0 y_0 k + (b^2 - y_0^2) = 0$$

两边同乘 $a^2 b^2$ 并用 $a^2 - x_0^2 = \frac{a^2}{b^2}y_0^2$、$b^2 - y_0^2 = \frac{b^2}{a^2}x_0^2$ 替换，恰配成完全平方：

$$\left(\frac{a}{b}y_0 k + \frac{b}{a}x_0\right)^2 = 0 \Rightarrow k = -\frac{b^2 x_0}{a^2 y_0}$$

代回点斜式 $y - y_0 = -\frac{b^2 x_0}{a^2 y_0}(x - x_0)$，两边同乘 $\frac{y_0}{b^2}$ 并移项，结合 $\frac{x_0^2}{a^2} + \frac{y_0^2}{b^2} = 1$ 得证：

$$\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = \frac{x_0^2}{a^2} + \frac{y_0^2}{b^2} = 1$$

### 方法二：光学性质 + 外角平分线定理法（几何巧证）
- **先证切线即外角平分线**：设 $l$ 为 $\angle F_1 P F_2$ 的外角平分线。假设 $l$ 上存在异于 $P$ 的另一椭圆点 $Q$，作 $F_2$ 关于 $l$ 的对称点 $F_2'$，则 $F_1$、$P$、$F_2'$ 共线而 $F_1$、$Q$、$F_2'$ 不共线，故 $2a = |QF_1| + |QF_2| = |QF_1| + |QF_2'| > |F_1 F_2'| = |PF_1| + |PF_2| = 2a$，矛盾！故 $P$ 是 $l$ 与椭圆唯一公共点，即 $l$ 为切线。
- **求切线与 $x$ 轴交点 $Q(x_Q, 0)$**：由外角平分线定理及焦半径公式得：

$$\frac{|QF_1|}{|QF_2|} = \frac{|PF_1|}{|PF_2|} \Rightarrow \frac{x_Q + c}{x_Q - c} = \frac{a + ex_0}{a - ex_0} \Rightarrow x_Q = \frac{a^2}{x_0}$$

- 于是斜率 $k_{PQ} = \frac{y_0 - 0}{x_0 - \frac{a^2}{x_0}} = \frac{x_0 y_0}{x_0^2 - a^2} = \frac{x_0 y_0}{-a^2 \frac{y_0^2}{b^2}} = -\frac{b^2 x_0}{a^2 y_0}$，写出点斜式整理即得 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$。

### 方法三：隐函数求导法（选填速推，大题慎用）
方程 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 两边同时对 $x$ 求导（把 $y$ 看作 $x$ 的函数）：

$$\frac{2x}{a^2} + \frac{2y \cdot y'}{b^2} = 0 \Rightarrow y' = -\frac{b^2 x}{a^2 y}$$

切点为 $P(x_0, y_0)$，故斜率 $k = -\frac{b^2 x_0}{a^2 y_0}$，写点斜式整理即得 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$（$y_0 = 0$ 单独验证成立）。

## 二、第二步：同构转化法秒证「切点弦」与「切线交点轨迹」

**同构转化法原理**：
- **一元同构**：若 $f(x_1) = 0$ 且 $f(x_2) = 0$，则 $x_1$、$x_2$ 可视为方程 $f(x) = 0$ 的两根；
- **二元同构**：若 $f(x_1, y_1) = 0$ 且 $f(x_2, y_2) = 0$，且 $f(x, y) = 0$ 为二元一次方程，则由「两点确定一条直线」知，$f(x, y) = 0$ 即为过 $A(x_1, y_1)$、$B(x_2, y_2)$ 的直线方程。

### 1. 证明曲线外切点弦 $AB$ 方程
设曲线外定点为 $P(x_0, y_0)$，两切点为 $A(x_1, y_1)$、$B(x_2, y_2)$。由第一步，切线 $PA$、$PB$ 方程分别为 $\frac{x_1 x}{a^2} + \frac{y_1 y}{b^2} = 1$ 与 $\frac{x_2 x}{a^2} + \frac{y_2 y}{b^2} = 1$。因两切线均过 $P(x_0, y_0)$，代入得：

$$\begin{cases} \frac{x_1 x_0}{a^2} + \frac{y_1 y_0}{b^2} = 1 \\ \frac{x_2 x_0}{a^2} + \frac{y_2 y_0}{b^2} = 1 \end{cases}$$

**反客为主（同构）**：上式表明 $A(x_1, y_1)$、$B(x_2, y_2)$ 均满足二元一次方程 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$，故直线 $AB$ 的方程即为 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$。

### 2. 证明曲线内弦 $AB$ 两端切线交点 $Q(x, y)$ 的轨迹
设两切线交点为 $Q(x, y)$（$Q$ 在曲线外），则弦 $AB$ 正是过 $Q$ 所作切线的切点弦！直接套用上面结论，切点弦 $AB$ 的方程为 $\frac{x \cdot X}{a^2} + \frac{y \cdot Y}{b^2} = 1$（$(X, Y)$ 为直线上动点）。

因弦 $AB$ 恒过曲线内定点 $P(x_0, y_0)$，将 $(x_0, y_0)$ 代入 $(X, Y)$，立刻得到交点 $Q(x, y)$ 满足的轨迹方程：

$$\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$$

*(几何上这体现「配极互反」：$P$ 在 $Q$ 的对应直线上 $\Leftrightarrow Q$ 在 $P$ 的对应直线上。)*
