# 点关于直线对称

> **来源**：补充专题（对称问题 3/4） ｜ **适用模块**：一、直线与方程

## 解题通法（垂直 + 中点联立方程组）

已知点 $P(x, y)$ 与直线 $l: Ax+By+C=0$，求点 $P$ 关于直线 $l$ 的对称点 $P'(x', y')$，抓住「**垂直**」与「**中点在对称轴上**」两个条件，列方程组联立求解：

$$\begin{cases} k_{PP'} \cdot k_l = -1 \quad (k_l \neq 0) \\ A \cdot \frac{x+x'}{2} + B \cdot \frac{y+y'}{2} + C = 0 \end{cases}$$

联立上述方程组即可解出 $x'$、$y'$。

## 典型例题

**例题**：已知直线 $l: y=3x+3$，求点 $P(4, 5)$ 关于 $l$ 的对称点 $P'$ 的坐标。

**解析**：设 $P'(x', y')$，线段 $PP'$ 的中点 $\left(\frac{x'+4}{2},\; \frac{y'+5}{2}\right)$ 在直线 $l$ 上，且 $PP' \perp l$，列方程组：

$$\begin{cases} \frac{y'+5}{2} = 3 \cdot \frac{x'+4}{2} + 3 \\ \frac{y'-5}{x'-4} \cdot 3 = -1 \end{cases} \Rightarrow \begin{cases} x' = -2 \\ y' = 7 \end{cases}$$

故对称点为 $P'(-2, 7)$。

## 常见对称轴的对称点速查表

已知点 $P(x_0, y_0)$，关于常见特殊直线的对称点 $P'$ 可直接套用：

| 对称轴 | 对称点 $P'$ 坐标 |
| --- | --- |
| $x$ 轴 | $P'(x_0,\; -y_0)$ |
| $y$ 轴 | $P'(-x_0,\; y_0)$ |
| 直线 $y=x$ | $P'(y_0,\; x_0)$ |
| 直线 $y=-x$ | $P'(-y_0,\; -x_0)$ |
| 直线 $x=m$ | $P'(2m-x_0,\; y_0)$ |
| 直线 $y=n$ | $P'(x_0,\; 2n-y_0)$ |
| 直线 $x-y+m=0$ | $P'(y_0-m,\; x_0+m)$ |
| 直线 $x+y-m=0$ | $P'(-y_0+m,\; -x_0+m)$ |
